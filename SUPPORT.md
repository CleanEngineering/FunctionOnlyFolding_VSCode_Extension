# Support

## Bug reports

Please open an issue in the GitHub repository:

https://github.com/CleanEngineering/FunctionOnlyFolding_VSCode_Extension/issues

Include, when possible:

- VS Code version
- Extension version
- Operating system
- TypeScript or TSX language mode
- A concise description and a sanitized code sample that reproduces the issue

Do not include credentials, private keys, secrets, or confidential source code.

## Feature requests

Feature requests are welcome through GitHub Issues. Please describe the TypeScript syntax or folding workflow you want to improve.
